## 2. Color Palette & Usage Rules
| Color Role | Hex Code | Usage Rules |
| :--- | :--- | :--- |

## 5. UI Component Rules
- **Watermark Standard:** Uploaded payment vouchers must automatically display the official "Learn With Sulav" logo watermark.
- **Data Masking:** Sensitive client data (such as phone numbers in lists) must be masked (e.g., `9841****89`) with an interactive toggle eye.
- **Card & Banner Generators:** When generating agent festival banners or vCards, always include the primary blue header (`#0A4F8A`), accent orange highlights (`#F15A24`), agent photo/name, and contact details.
